# Model latihan Job Kelas Extrim

File pada folder ini disalin dari model latihan yang diberikan pengguna.

| Nama tampilan | File web | Format sumber |
| --- | --- | --- |
| Job Kelas Extrim | `job-kelas-extrim.SLDPRT` | SolidWorks Part |

Halaman 2D ke 3D hanya memuat Job Kelas Extrim. Berkas `job-kelas-extrim.stl` dipakai untuk penampil web; `job-kelas-extrim.SLDPRT` disediakan sebagai unduhan untuk dibuka di SolidWorks.

Mesh STL berisi 1.940 segitiga dengan batas ukuran 230 × 225 × 80 mm. Pratinjau mesh membantu membaca bentuk; ukuran produksi tetap mengikuti gambar kerja dan berkas CAD sumber.

`views-extrim` adalah hasil eksperimen proyeksi rusuk yang belum membedakan garis tampak dan tersembunyi. Halaman pembelajaran tidak memakai gambar tersebut.
